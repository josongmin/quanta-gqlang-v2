# CodeQL Java source audit for the code-query RFC

> 고정 SHA의 소스 감사 기록이다. 로컬 구현·계획 언급은 감사 시점 관찰이며, 현행 판단은 [근거 인덱스](../2026-10-04-reference-source-review.md)와 [RFC](../../rfcs/2026-10-04-code-query-dsl-and-substrate.md)를 따른다.

- Upstream: `https://github.com/github/codeql`, cloned at `f7617abe602d4763cd08c6a57b6a6bc347e7e325` (2026-10-04 review).
- Scope: checked-in Java QL library, shared data-flow QL implementation, one production SQL-injection query, model extensions and checked-in expected output. Source inspection only; CodeQL CLI/evaluator and corpus execution were not tested.
- Boundary: this repository exposes query and library source. It does **not** expose enough of the CodeQL evaluator to infer its physical planning, storage indexes, query budget behavior or deterministic chosen path algorithm. Those remain unverified here.

## Reachable implementation chain

1. Java [DataFlow.qll](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/lib/semmle/code/java/dataflow/DataFlow.qll#L8-L15) and [TaintTracking.qll](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/lib/semmle/code/java/dataflow/TaintTracking.qll#L8-L17) compose language-specific layers over the shared data-flow library. Treat syntax, Java facts, shared flow, and query/model customization as separate ownership surfaces.
2. The shared [ConfigSig](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/shared/dataflow/codeql/dataflow/DataFlow.qll#L401-L450) exposes source, sink, barriers in/out, additional edges, and explicit field/access-path limits. [StateConfigSig](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/shared/dataflow/codeql/dataflow/DataFlow.qll#L519-L575) adds source/sink state and state-specific barriers/steps. A real Java query [uses state transitions](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/src/Security/CWE/CWE-200/AndroidWebViewSettingsAllowsContentAccess.ql#L64-L107), so a generic source/sink/barrier triple is insufficient for claimed stateful checks.
3. The Java SQL-injection library [defines source, sink, barrier and extra taint step](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/lib/semmle/code/java/security/SqlInjectionQuery.qll#L14-L42). The production [path query](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/src/Security/CWE/CWE-089/SqlTainted.ql#L1-L23) imports its `PathGraph`, requests `flowPath(source,sink)`, and selects sink/source/sink path nodes. This is a specialized taint configuration plus a result projection, not ordinary call-graph BFS.
4. Shared [GlobalFlowSig](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/shared/dataflow/codeql/dataflow/DataFlow.qll#L707-L738) distinguishes endpoint `flow` and `flowPath`; `PathGraph` exposes edges/nodes/subpath summaries [here](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/shared/dataflow/codeql/dataflow/DataFlow.qll#L680-L694). Implementation [constructs endpoint path nodes and explanation edges](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/shared/dataflow/codeql/dataflow/internal/DataFlowImpl.qll#L2581-L2629). Source does not promise a universal shortest or lexicographically minimal witness; the prior RFC's universal representative-path rule requires its own solver algorithm and proof.
5. Model extensions are executable library inputs: [source/sink/barrier/guard/summary/neutral schemas](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/lib/semmle/code/java/dataflow/internal/ExternalFlowExtensions.qll#L9-L54) accept API identity, access path, kind, provenance and extension identity. Checked-in examples mark `ServletRequest.getParameter` as a remote [source](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/lib/ext/jakarta.servlet.model.yml#L1-L17) and `JdbcTemplate.query` argument 0 as a SQL-injection [sink](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/lib/ext/org.springframework.jdbc.core.model.yml#L1-L15). The source code shows `ExtensionId` participation; it does not prove what exact package digest the external CLI records.
6. SQL-injection query [expected output](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/test/query-tests/security/CWE-089/semmle/examples/SqlTainted.expected#L1-L15) records location-level alerts and path-graph rows. This is the right comparator shape, but its checked-in expected result is not independent ground truth. The example query deliberately contrasts concatenated SQL with a prepared statement [here](https://github.com/github/codeql/blob/f7617abe602d4763cd08c6a57b6a6bc347e7e325/java/ql/src/Security/CWE/CWE-089/SqlTainted.java#L1-L17).

## RFC impact

| RFC item | Source-based verdict | Required correction or gate |
| --- | --- | --- |
| A09 model pack | Structurally necessary. CodeQL has real, typed model categories and API paths; our named Java pack must correspond to actual Semantica facts/solver semantics. | Specify matching precedence, subtype/signature matching, access-path selectors, provenance, conflicts, version identity and unknown-library fallback. Test two conflicting models and an absent model. |
| A10 `flow`/CHECK | Specialized stateful analysis and explanation graph are separate from endpoint relation evaluation. | Make path support conditional on selected solver capability. For a path-required query, absence of supported path materialization is `Unsupported`/`Incomplete` as appropriate, never an empty success. Verify every emitted step in solver relation and flow state. |
| Prior RFC `shortest + lexical` witness | Not established by this checked-in CodeQL source, and Joern uses another policy. | Replace universal promise with versioned `representative_path_policy` capability. Claim shortest only for a Semantica algorithm with a finite state graph, stable keys, and independent proof. |
| A14 comparison | Exact Java library, query, model extensions and evaluator/tool version matter. | Pin CodeQL CLI/version separately from this repo SHA, the query pack, model pack, extraction database/source, and results. Run same labeled corpus; compare normalized endpoints and independently validate paths. |

No claim here covers the proprietary CodeQL evaluator's optimizer, snapshot behavior, resource limits, shortest-path selection, or production alert quality.
