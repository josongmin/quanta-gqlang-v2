## Reachable query path

1. [`ClientContext` plans and optimizes the bound statement](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/main/client_context.cpp#L470-L474); execution [maps the logical root to physical operators inside the transaction helper and invokes the query processor](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/main/client_context.cpp#L489-L531). The [optimizer pass order](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/optimizer/optimizer.cpp#L22-L59) includes filter, projection and limit pushdown before factorization.
2. `MATCH` [binds a graph pattern](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/binder/bind/read/bind_match.cpp#L37-L40). A variable-length edge binds lower/upper depth, path semantic, node/edge IDs, optional direction and projected path properties; it chooses a traversal function by relation kind ([binder](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/binder/bind/bind_graph_pattern.cpp#L440-L489), [dispatch](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/common/enums/query_rel_type.cpp#L11-L49)). The binder rejects depths over the configured maximum and invalid shortest-path lower bounds ([source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/binder/bind/bind_graph_pattern.cpp#L526-L552)); the default maximum is 30 ([config](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/include/main/client_config.h#L11-L22)).
3. Join-order planning [routes variable-length/shortest relations to `appendRecursiveExtend`](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/planner/plan/plan_join_order.cpp#L303-L320). That creates a logical recursive operator, optional node mask, path property lookup and an ID hash join back to the input node ([source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/planner/plan/append_extend.cpp#L99-L164)). The general [physical mapper](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/processor/map/plan_mapper.cpp#L24-L44) dispatches that operator to a physical `RecursiveExtend` with `OnDiskGraph`, shared result table, masks and aligned table scan ([source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/processor/map/map_recursive_extend.cpp#L26-L69)).
4. The graph adapter prepares an edge scan with the request transaction and selected relationship columns; [`scanFwd`/`scanBwd`](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/graph/on_disk_graph.cpp#L195-L223) read adjacency by node ID. Its iterator evaluates a relationship predicate and destination mask after storage scan ([source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/graph/on_disk_graph.cpp#L237-L260)); the relationship scan state accounts for committed and transaction-local data ([source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/storage/table/rel_table.cpp#L30-L53), [source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/storage/table/rel_table.cpp#L83-L117)). These internal transactions do **not** establish a cross-repository Semantica/Index source closure.
5. Recursive execution iterates source IDs, runs graph frontier computation, writes destination/path rows and merges per-worker factorized tables ([source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/processor/operator/recursive_extend.cpp#L86-L157)). Frontier workers scan adjacency in both directions as needed ([source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/gds_task.cpp#L41-L122)). The graph frontier and parent records are distinct from the final row table ([variable-length source](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/variable_length_path.cpp#L52-L85)).

## Semantics and operational findings

| Observed behavior | Evidence | Consequence for QGLang/Semantica |
| --- | --- | --- |
| `WALK` allows repeated edges/nodes, `TRAIL` rejects repeated edge IDs, and `ACYCLIC` rejects repeated intermediate node IDs. These are checked while reconstructing a path, not encoded by a generic endpoint BFS result. | [output writer](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/output_writer.cpp#L242-L288); checked-in [`WALK` versus `TRAIL` count fixture](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/test/test_files/recursive_join/semantic.test#L5-L18). | Graph query policy must specify allowed path repetition, identity key, and count multiplicity. Endpoint reachability alone cannot certify a trail/simple-path result. |
| `SHORTEST` stores one first-discovered parent for a destination; `ALL SHORTEST` retains parents first discovered in the current BFS level. The former makes no lexical tie-break promise in inspected code. | [single](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/ssp_paths.cpp#L23-L53), [all](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/asp_paths.cpp#L22-L45), [all-shortest fixture](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/test/test_files/shortest_path/all_shortest_path.test#L10-L30). | `one shortest`, `all shortest`, and deterministic representative witness are different capabilities. An `all shortest` result may have multiple rows per endpoint; explicit tie-order proof is needed for reproducible first witness. |
| Projection pushdown switches shortest algorithms to endpoint-only variants and suppresses path tracking for variable-length paths when path values are unused. | [optimizer](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/optimizer/projection_push_down_optimizer.cpp#L49-L69). | A typed result requirement can avoid provenance materialization, but a requested witness must retain edge IDs, direction, source identity and checked steps. |
| Factorized rows carry multiplicity into hash join build; path enumeration/limit counts rows. | [join build](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/processor/operator/hash_join/hash_join_build.cpp#L62-L72), [writer](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/output_writer.cpp#L87-L105). | Set reachability, path rows, and SQL-style bag rows must have distinct result types or declared coercions. `COUNT(*)` depends on path policy. |
| `LIMIT` is pushed through a narrow `HASH_JOIN`/`PATH_PROPERTY_PROBE` shape to the recursive operator, whose results are materialized before a table scan. | [pushdown](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/optimizer/limit_push_down_optimizer.cpp#L50-L70), [TODO: not pipelined](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/include/planner/operator/extend/logical_recursive_extend.h#L52-L57), [mapper](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/processor/map/map_recursive_extend.cpp#L26-L69). | Early limit is an optimizer rule with a proof precondition. A capped prefix must not answer exhaustive `COUNT`, absence, or CHECK completion. |
| The query runs inside an engine transaction, has timeout/cancellation checks at operator and graph iteration/path reconstruction boundaries, and holds path/result state in memory-managed structures. | [transaction execution](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/main/client_context.cpp#L489-L534), [frontier check](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/gds_utils.cpp#L60-L67), [writer check](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/output_writer.cpp#L87-L95), [worker loop](https://github.com/kuzudb/kuzu/blob/89f0263cc7a1fd9c396d2c4953747a013556a7f9/src/function/gds/gds_task.cpp#L41-L63). | Keep A06/A10 request-owned budget, bounded cancellation and final completion gates. The inspected worker inner loop contains no explicit interrupt check; this audit did not measure its worst-case response or prove an OOM vulnerability. |

## Plan deltas

1. Add a **graph access profile** under A01-F/A05: exact neighbor enumeration by direction; stable node/edge identity; relationship-predicate exactness or residual semantics; bound source closure; finite cardinality/cost and cursor status. Quanta Index search is not an adjacency index by implication.
2. In A03/A08/A10, type graph result policy explicitly: endpoint set versus path bag, `walk`/`trail`/`acyclic`, one shortest versus all shortest, zero-length handling, max hops and deterministic tie policy. Unsupported combinations reject at admission. A flow witness has additional call/return/state/model constraints and cannot inherit ordinary graph-path completion.
3. In A06/A08, admit path property lookup and early `LIMIT` only under independent result equivalence. Test parallel edges, cycles, repeated edge/node, equal shortest paths, row multiplicity, path unused, direction reversal and `ORDER BY`/`LIMIT` with different physical row order.
4. In A10, retain predecessor keys and lazily materialize bounded evidence only when requested. Validate every reconstructed edge under the same admitted source closure; cancellation, memory or depth caps produce typed non-completion when the query requests exhaustive results.
5. Keep Kuzu out of the production dependency decision: archived source, C++ engine/storage integration cost, and different transaction/source authority. Compare these patterns against the existing Semantica graph owner on a fixed factual fixture before selecting an implementation.

## Proof boundary

Source review and existing fixture inspection support the architectural observations above. This audit does not prove Kuzu's fixture suite passes at this SHA, prove actual Semantica coverage, or establish performance or deterministic witness ordering under parallel execution.
