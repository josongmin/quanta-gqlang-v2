## Outcome

1. Replaced open relation composition tags with direct inner/cross join,
   group-by, and order-by HIR. Inner join requires `on`; cross join cannot carry it.
2. Added checked non-empty group/order keys and logical binders with retained
   binder spans. Split logical quantifiers from relational EXISTS/NOT EXISTS.
3. Added `CallArgHirV1::{Expr, Star}` plus private-backed checked
   `CallArgsHirV1`. `CallExprV1.args` is private, every ingress uses the checked
   carrier, mixed/multiple Star lists reject, and Star spans participate in integrity.
4. Closed composition producer/body slots. SAMPLE and EXPLAIN use variant-specific
   nodes. USE PACK activation is restricted and its lockfile is required by type.
5. Added HIR-owned source/document identity (`SourceIdV2`, `LocatedSpanV2`,
   `HirDocumentV1`) and one document-wide integrity collector. The bounded V2
   parser accepts caller-owned source identity; the legacy wrapper exposes none.
6. Added immutable parse budgets and one shared counter for tokens including EOF,
   document items, expression nodes/depth, collection width, and projection width.
7. Repaired UTF-8 lexing and installed a closed escape grammar. Byte spans remain
   byte offsets. Identifier/integer/float/string lexing now scans and validates
   bounds, charges the token, and only then copies or decodes variable payloads.
   Formatter control escapes are canonical and lowercase.
8. Made value and Bool formatting precedence/associativity aware. Structural
   round trips now use an independent visitor-derived id/span-free witness.
9. Migrated owner-local tests to the new HIR and deleted the obsolete open-compose
   fallback rail. Added budget, source identity, located-span, cross-root ID,
   programmatic precedence, Unicode/escape, and compile-fail rails.
